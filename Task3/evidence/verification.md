# Техническая проверка проекта

Реально выполнено при подготовке архива:

- Подтверждено, что во всех четырёх CSV сохранены записи из SQL-постановки: 5+10+20+30 строк данных.
- Проверены внешние ключи `goods_list.id_good → good.id`, `goods_list.id_delivery → delivery.id` и `delivery.id_darkstore → darkstore.id`.
- Выполнен независимый расчёт сумм Decimal из исходного CSV и трёх новых тестовых позиций. Числа записаны в `csv_check.txt`.
- Java 21 успешно скомпилировала `Domain.java` и `CsvDataLoader.java`.
- Синтаксис `DarkstoreReactiveApp.java` также проверен с временными заглушками API RxJava (не входящими в архив).

**Не выполнено в данной среде:** полная Maven-сборка с настоящим RxJava 3 и запуск реактивной цепочки. Maven и необходимые jar отсутствуют локально, а загрузка зависимости недоступна. Поэтому здесь нет заявлений о проверенном запуске RxJava и нет сгенерированных «скриншотов доказательств» вместо реальных.

Для полной проверки импортируйте проект в IntelliJ IDEA c интернет-доступом, загрузите зависимости и выполните `mvn compile exec:java` либо запустите `main()`; сделайте подлинные скриншоты согласно README.
